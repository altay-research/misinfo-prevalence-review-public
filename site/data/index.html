Each freeze is immutable, MD5-stamped and git-tagged; the ledger of freezes and the append-only research log ship with the code. Every figure and statistic regenerates from the frozen file by one pipeline, and a drift check fails the build if any document contradicts the canonical counts.

Tell us about a study we missed

It opens a pre-filled issue on the public repository. What makes a submission usable: the DOI, the quantity as the paper words it, and the denominator it is a share of. Submissions are public and dated, and are screened against the same eligibility criteria as everything else.

Found a coding error?

Every estimate record carries a flag a coding error link that opens an issue pre-filled with that estimate's identifier and its current coding. Disagreements arrive dated and public rather than in an inbox, which is the point: the quotes are on the site so the coding can be contested against the source.
