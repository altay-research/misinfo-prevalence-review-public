Start here: this is a component view. The narrative dashboard is phaseB_dashboard.html; the interactive explorer is companion_dashboard.html.

Source estimates_v1.7.23_frozen.csv. Main-analysis set = general-public rows (no demographic subgroup), a real proportion, not within-misinfo composition → 934 estimate rows. Primary statistic = study-level median (median-per-study, then across studies); estimate-level shown alongside. Prevalence excludes QUALITY/OTHER.

Read this first — the estimand matters more than any single number. "Prevalence of misinformation" is not one quantity. Audience exposure (EXPOSURE = share of a real information diet; REACH = % of people who saw ≥1; RECALL = % who report seeing it) answers "how much misinfo do people actually encounter?" — the review's core question. CONTENT (% of items in a sample that are misinfo) answers a different question and is usually measured on topic-curated samples, so it runs much higher. Slice within these, never pool across them.
