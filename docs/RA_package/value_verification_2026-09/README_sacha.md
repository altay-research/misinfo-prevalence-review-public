# Value verification package (built from estimates_v1.7.14_frozen.csv)

Open `code_V_sacha.html` in a browser (keep the `papers/` folder next to it). One paper at a time:
the paper on the left, the estimates to verify on the right. Everything saves in the browser;
press "Download" whenever you stop and send the CSV.

Tiers: 1 = behavioural exposure, reach, concentration (40 papers, 114 estimates);
2 = sharing (23, 50); 3 = survey recall (26, 57).
Total 89 papers, 221 estimates. Papers without a PDF are shown as a text extraction.
The answer key is NOT in this folder.
