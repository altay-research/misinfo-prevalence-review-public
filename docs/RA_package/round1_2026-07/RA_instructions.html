Misinformation prevalence review — coding task

Thanks for helping! You'll code 100 papers for a review of how prevalent misinformation is in people's information environments. For each paper there are two steps: (1) is there a valid misinfo-prevalence estimate? (2) if yes, which type, and what's the value.

Files: the RA_coding_sheet.xlsx — read the Examples tab first (one of every type, coded), then fill the Coding tab (its rows are in the same order as the numbered PDFs in the pdfs/ folder). If two of you code: work independently, don't compare notes until done.

Step 1 — is it a valid prevalence estimate? (RA_keep)

KEEP (Y) only if the sample was drawn neutrally — by topic / keyword / popularity / random / whole census.

Mark DROP (N) if it's actually:

  • Composition within an already-misinfo set — the sample is known-false / fact-checked / rumor items, so any % just describes that misinfo set (e.g. "43% of the false posts were about vaccines", or "X% of fact-checked claims were rated false").
  • A content-quality / usefulness scale (DISCERN, GQS, JAMA — how reliable, clear or complete a page/video is), not whether it is false.  BUT classifying sources as "untrustworthy / low-credibility" (e.g. NewsGuard, Media Bias/Fact Check) and measuring exposure/sharing of them is a valid misinfo measure → keep those (see the EXPOSURE example).
  • A stance / sentiment measure (e.g. "anti-vaccine"), not false-vs-true.
  • A source / website-level rating, not the content people see.
  • Concentration among creators / sources (not the audience), or relative virality ("false spreads faster").

Put the drop-reason in RA_notes.

Which figure(s) to report

A paper can contain many numbers. Report the prevalence figure(s) — how much of the content / a diet / people / sharing is misinformation, using the broadest, whole-sample denominator the paper gives.

If the paper breaks the figure down (by platform, country, topic, year): put the overall / total in the columns and list the breakdowns in RA_notes. If there is no overall, put any one in the columns and list them all in notes.

Do NOT report these (they are not the prevalence):

  • the complement — "% that were true / accurate / reliable";
  • a breakdown within the misinformation — "of the false posts, 43% were about vaccines";
  • a sub-group / conditional figure — "among conservatives, X%" (use the whole-sample figure instead);
  • quality / stance / sentiment scores (those make it a DROP — see Step 1).

Step 2 — which type? (RA_construct, only if Keep = Y)

ConstructWhat it is
CONTENT% of content items that are false, vs a neutral sample. e.g. "9% of vaccine tweets were false."
EXPOSURE% of a person's information diet that is misinfo. e.g. "0.3% of their news browsing."
REACH% of people who encountered (saw/visited) misinfo ≥1 time in a period.
SHARINGObserved sharing behaviour — % of people who shared ≥1 misinfo item, or % of shared content that is misinfo.
RECALLSelf-reported (survey) seeing/sharing misinfo.
CONCENTRATIONHow unevenly misinfo is spread across people — for exposure ("the top 1% of users saw 80% of all misinfo") or sharing ("1% of users shared 50% of the fake news").

Also fill

  • RA_value — the % (or count) you find.
  • RA_notes — which estimate you coded; the drop-reason if N; anything unclear.
  • RA_notes — list every distinct prevalence figure as "value | type" (e.g. "8% | CONTENT (YouTube); 43% | CONTENT (TikTok)"); the drop-reason if N; anything unclear.
