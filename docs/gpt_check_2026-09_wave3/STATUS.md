**What this pass is for.** GPT extracts each paper's quantitative estimates from full
text, blind to our coding. Agreement statistics cannot show what a lone coder MISSED,
and wave 3 was extracted by one person; this pass is the check for omissions. One paper
per fresh GPT session, reply saved as `returns/<paper_id>.json`, then scored against
ours.

## Files

- `INSTRUCTIONS.md` — the extraction prompt (constructs, output schema); reproduced at
  the top of every batch file. Generated.
- `MANIFEST.md` — table of the last build (8 papers; `handfound_01` and `scholar_03`
  date from the earlier build and are not in it). Generated — do not hand-edit.
- `batches/<id>.md` — what gets pasted into GPT; `batches/<id>.json` — the source record
  it was built from.
- `returns/<id>.json` — GPT's replies.
- Scoring reads `returns/` plus our coding in
  `data/extract_v2/wave3_2026-09/extractions/` and writes `…/blind_queue.csv`.
