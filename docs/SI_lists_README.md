# Supplementary lists (PRISMA 2020 items 16b and 17)

Generated by `scripts/make_si_lists.py` from the record ledger (`data/synth/prisma_terminal_states.csv`,
one row per identified record, built by `scripts/prisma_ledger.py` and checked by
`scripts/validate_prisma.py`). Freeze v1.7.26. Do not hand-edit.

| file | rows | content |
|---|---|---|
| `si_included_studies.csv` | 512 | included studies (item 16b) |
| `si_fulltext_exclusions.csv` | 1350 | every report excluded at full text, all sources and passes (item 17; Supplementary Data 2) |
| `si_not_retrieved.csv` | 1153 | every report sought and not retrieved |
| `si_other_reports.csv` | 5 | second reports (preprint or duplicate copy) of included studies |
| `si_rescreen_exclusions.csv` | 48 | records excluded at the second-reader title/abstract re-screen |

In `si_fulltext_exclusions.csv`, `stage` names the pass that took the decisive decision; `recovered_by` is
filled when the first screen had excluded the record and a later re-screen sent it to full text;
`reason_category` is the group drawn on the flow diagram, assigned by the ordered rules in
`prisma_ledger.REASON_CATEGORIES` from the recorded reason; `reason_detail` is the recorded reason,
verbatim; `reason_source` is the file it comes from. 0 rows carry no recorded reason and say so.

Bibliography gaps among included studies: 35 without a first author, 0
without a year, 13 without a venue, 10 without a DOI.
